# Web format

A web is a folder. Nothing else is needed: no database, no server.

```
spider/
  profile.md          who the user is, role, capture mode
  index.md            one line per thread, generated
  catalogue.md        reusable functions, classes, fixtures from the code (test automation webs, generated by harvest)
  usage.log           feedback: used / helped / wrong per thread (append-only, tab-separated)
  evals.json          optional retrieval test cases; evals-baseline.json holds the last accepted results
  threads/
    account/
      northwind.md
    person/
      jane-doe.md
    _archive/         threads no longer active
```

Thread folders are named after the thread types in the role file.

## profile.md

```markdown
---
name: Alex Morgan
role: qi-practice-head
capture_mode: confirm      # confirm | auto | manual
stale_after_days: 90
---
- Extra never-store rules or preferences, one per line.
```

## Thread file

```markdown
---
id: northwind
type: account
name: Northwind Logistics
aliases: [Northwind, NWL]
tags: [retail, test-automation]
status: active
links: [jane-doe, northwind-rfp-2026]
use_when: [logistics, warehouse]   # optional: words that should bring this thread up
---
- 2026-10-02 [contact] Met [[jane-doe]], Head of QA, at their Leeds office
- 2026-10-02 [insight] Regression takes 3 weeks per release; they want it under 1
- 2026-10-09 [commitment open due:2026-10-20] Send POC scope to [[jane-doe]]
- 2026-10-18 [commitment done] Send POC scope to [[jane-doe]] src:email "POC scope v1"
```

Frontmatter rules:

- `review` (pattern threads, governed mode): `candidate`, `approved` or `retired`, with `approved_by` / `approved_on` or `retired_by` / `retired_on` / `retired_why`. Set by `spider.py approve` and `retire`, never by hand or by an agent.
- `use_when` (optional) is a list of trigger words and phrases. `spider.py match` returns the thread when any of them appears in a request. Use it on pattern and how-to threads, with synonyms.
- `id` matches the file name without `.md`. Lowercase, digits and hyphens.
- `type` is one of the role's thread types and matches the folder.
- `name` is required. `aliases`, `tags`, `links` are lists in `[a, b]` form. `status` is `active`, `paused` or `closed`.

## Strand line

```
- YYYY-MM-DD [kind attr attr] text
```

- `kind` is one of the role's strand kinds.
- Attributes, space separated, all optional:
  - `open` / `done` for commitments
  - `due:YYYY-MM-DD`
  - `superseded` when a newer strand replaces this one
  - `avoid` when the line records a shortcut (sleep, force, raised timeout, removed assertion): shown as a warning, never as guidance
  - `by:<name>` who found it (evidence in governed mode; removed from kits)
  - `who:<thread-id>` when the strand is about a person
- Text can link threads with `[[thread-id]]`, carry the error it fixes as `error:"<message>"`, and cite a source with `src:...` at the end.
- Secrets and personal details are removed when a line is written; `spider.py scan` checks existing files.

Lines that don't start with `- ` followed by a date are free notes and are ignored by the tools.

## index.md

Generated by `spider.py index`. One line per thread:

```
- [account] northwind: Northwind Logistics (aka Northwind, NWL) #retail #test-automation, 4 strands, last 2026-10-18, 0 open
```
